# FloraScane_LiveTelemetry

FloraScan Flutter application with ESP32 BLE telemetry for raw soil moisture ADC, ambient temperature, relative humidity, and raw light ADC.

- Flutter application: `mobile/`
- Arduino-compatible firmware: `firmware/FloraWandTelemetry/`
- [Protocol, firmware upload, testing, and verification guide](docs/phase1-telemetry.md)

Firmware compilation and physical ESP32/Android operation have not yet been verified.
